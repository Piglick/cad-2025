# Лабораторная работа №1. Введение в Spring Boot

## Цель работы

Получить практические навыки работы со Spring Boot.

## Ход работы

Был создан проект на Java с использованием Maven и Spring Boot. В проект добавлена зависимость Spring Web. Приложение успешно запустилось на порту 8080.

В классе MessageController были созданы методы для получения списка сообщений, добавления нового сообщения, изменения и удаления сообщения по индексу. Запрос к главной странице возвращает строку `Hello, World!`.

Для дополнительного задания были добавлены два метода: очистка всего списка сообщений и получение количества сообщений.

## Результаты проверки

В браузере проверены главная страница и пустой список сообщений. Через PowerShell проверены добавление, изменение и удаление сообщения. Сервер вернул сообщения об успешном выполнении этих операций.

Дополнительные методы также были проверены через PowerShell. Количество сообщений до добавления было равно 0, после добавления - 1, после очистки списка - снова 0.

## Вывод

Было создано и запущено приложение Spring Boot для работы с сообщениями. Основные операции и два дополнительных метода были проверены.


# Лабораторная работа №2. Spring MVC

## Цель работы

Получить практические навыки работы со Spring Framework.

## Ход работы

Был создан проект на Java 21 с использованием Maven и Spring Boot 4.2.0. В проект добавлены зависимости Spring Web и Thymeleaf. Приложение успешно запустилось на порту 8080.

Разработано веб-приложение ToDo List для управления списком задач с использованием архитектуры Spring MVC.

Были созданы классы Task, TaskRepository, TaskService и TaskController. Реализованы методы добавления, отображения, удаления задач и изменения их статуса выполнения.

Для отображения задач создан HTML-шаблон index.html с использованием Thymeleaf.

В качестве дополнительного задания №3 была реализована функция подтверждения удаления задачи с помощью JavaScript.

## Результаты проверки

В браузере по адресу `http://localhost:8080` проверена работа веб-приложения.

Успешно проверены добавление новых задач, отображение списка, изменение статуса с Pending на Completed и удаление задач.

Дополнительная функция подтверждения удаления также была проверена. При нажатии Delete появляется окно подтверждения. При выборе «Отмена» задача остаётся в списке, при выборе OK - удаляется.
